# Shell Emulator
эмулятор командной оболочки UNIX-подобной операционной системы

# Вариант
вариант №11

# Этап 1
на первом этапе реализованы:
1) консольный интерфейс
2) REPL
3) приглашение к вводу с именем VFS
4) простой разбор команд по пробелам
5) команда-заглушка 'ls'
6) команда-заглушка 'cd'
7) команда 'exit'
8) обработка неизвестных команд

# Запуск
первый способ:
```bash
./run.sh
```
второй способ:
```bash
python3 src/main.py
```
# Пример работы
```text
my_vfs> ls
ls []

my_vfs> ls home
ls ['home']

my_vfs> cd
cd []
my_vfs> cd home
cd ['home']

my_vfs> hello
Unknown command: hello

my_vfs> exit
```
# Тестирование
 Для запуска тестов:
```bash
 python3 -m unittest discover -s tests
 ```
 На этапе 1 реализовано 6 тестов для проверки парсера, команд `ls`, `cd`, `exit` и обработки неизвестной команды
